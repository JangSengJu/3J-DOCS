## 1. 과금 단위 (BillingUnit)

| 값 | 표시 | 의미 |
| --- | --- | --- |
| `hour` | 시간 | 사용 시간당 과금 |
| `lcu_hour` | LCU·시간 | 로드밸런서 용량 단위당 과금 |
| `month` | 개 | 개수당 월 과금 |
| `gb_month` | GB·월 | 저장 용량당 월 과금 |
| `gb_transfer` | GB | 전송량당 과금 |
| `gb_second` | GB-초 | 함수 실행량 과금 |
| `million_requests` | 백만 건 | 요청 백만 건당 과금 |
| `request` | 건 | 요청 건당 과금 |

**시간 단위 과금(`hour`, `lcu_hour`)은 수량 대신 사용 시간을 선택한다.**

## 4. 무료 티어 (계정 기준)

월 비용 = `max(0, 수량 − 무료 티어) × 단가`

| 단위 | 무료 티어 |
| --- | --- |
| 백만 건 (`million_requests`) | 1 |
| GB-초 (`gb_second`) | 400,000 |
| GB (`gb_transfer`) | 100 |
| 그 외 단위 | 0 |

## 6. 등록 폼 선택지

| 항목 | 값 |
| --- | --- |
| 사용률 (`usage`) | `<5%`, `5~20%`, `>20%` |
| 필요도 (`need`) | `대부분 유휴`, `항상 필요` |
| 기본 예산 한도 (`DEFAULT_LIMIT`) | 60 (USD) |

## 7. 이름 자동 생성 규칙

이름을 입력하지 않으면 `{유형 소문자}-{사양 소문자}` 규칙으로 생성한다. 영숫자 외 문자는 `-` 로 치환하고 앞뒤 `-` 를 제거한다.

| 입력 | 결과 |
| --- | --- |
| `EC2` + `m5.large` | `ec2-m5-large` |
| `RDS` + `db.t3.small` | `rds-db-t3-small` |

## 부록. 데모용 시드 리소스 (코드 잔존)

`constants.ts` 의 `SEED_RESOURCES` 는 데모용으로만 남아 있는 상수다. 실제 서비스는 초기 템플릿 리소스를 제공하지 않으며 신규 사용자는 빈 목록으로 시작한다.

| 이름 | 유형 | 월 비용 | 사용률 | 필요도 | 구성 |
| --- | --- | --- | --- | --- | --- |
| web-server | EC2 | $70.08 | `<5%` | 대부분 유휴 | EC2 · m5.large · 730 시간 |
| db-main | RDS | $24.82 | `5~20%` | 대부분 유휴 | RDS · db.t3.small · 730 시간 |
| media-bucket | S3 | $2.30 | `5~20%` | 항상 필요 | S3 · Standard · 100 GB·월 |
