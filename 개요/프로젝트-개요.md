# 3J 프로젝트 개요

> AWS 리소스를 등록하면 예산 초과를 확인하고, AI 절감 추천과 개선 보고서까지 받는 비용 최적화 서비스

| 항목 | 내용 |
| --- | --- |
| 서비스명 | 3J |
| 한 줄 설명 | AWS 리소스 비용 예측·절감 추천·보고서 생성 웹 서비스 |
| 백엔드 | Java 17 + Spring Boot |
| 프런트엔드 | React |
| 인증 | JWT (Access Token + Refresh Token) |
| AI | Gemini (서버에서 호출, 실패 시 폴백) |
| 문서 버전 | v1.0 |
| 작성일 | 2026-10-12 |

---

## 1. 무엇을 하는 서비스인가

3J 는 클라우드(AWS)를 쓰는 사용자가 **리소스를 직접 등록**하면 다음 흐름을 제공한다.

```
회원가입 → 로그인 → 리소스 등록 → 예산 초과 확인
                                   │
                                   ▼
                        AI 절감 추천 → 개선 보고서(PDF)
```

1. **비용 계산** — 서울 리전 온디맨드 단가 카탈로그로 월 예상 요금을 자동 계산한다.
2. **예산 관리** — 월 예산 한도를 정하면 초과 여부를 즉시 알려준다.
3. **AI 추천** — Gemini 가 비용·성능·안정성·보안·확장성·아키텍처 관점의 개선안을 제안한다.
4. **보고서** — 6개 섹션 마크다운 보고서를 실시간(SSE)으로 만들고 PDF 로 내보낸다.

---

## 2. 기술 스택

| 계층 | 기술 | 비고 |
| --- | --- | --- |
| 프런트엔드 | React | SPA, 서버 API 호출 |
| 백엔드 | Java 17 + Spring Boot | REST API + SSE |
| 인증 | Spring Security + JWT | Access(30분) / Refresh(14일) |
| 데이터베이스 | RDBMS | 사용자·리소스·예산·Refresh 토큰 저장 |
| AI | Gemini API | 서버에서만 호출, 키 미노출 |
| 보고서 스트리밍 | SSE (Server-Sent Events) | `text/event-stream` |

---

## 3. 핵심 설계 원칙

| 원칙 | 설명 |
| --- | --- |
| 안전한 인증 | 회원가입/로그인 분리, 자동 가입 없음, Access/Refresh 토큰 |
| 무중단 AI | AI·키 실패 시 규칙 기반(폴백) 추천·보고서로 항상 결과 제공 |
| 서버 중심 | AI 호출·저장·검증을 모두 서버가 담당, 키 노출 없음 |
| 입력 정규화 | 서버가 화이트리스트·상한으로 본문을 조용히 정규화 |
| 근거 기반 | 요금 카탈로그 + 리소스 지표(사용률·필요도)를 프롬프트에 포함 |

## 4. 주요 기능 요약

| 영역 | 기능 |
| --- | --- |
| 인증 | 회원가입, 로그인, 토큰 재발급, 로그아웃, 세션 복구 |
| 대시보드 | 리소스 등록/삭제, AI 노트, 사용 용도, 예산 한도, 초과 알림 |
| 비용 | 월 요금 자동 계산(무료 티어 반영), 이름 자동 생성 |
| AI | 절감 추천(최대 15건), 추천 카드, 보고서 스트리밍, PDF, 폴백 |

전체 기능 목록은 [기능명세서](../기능명세서/기능명세서.md) 참고.

## 5. 데이터 모델

| 모델 | 설명 | 주요 필드 |
| --- | --- | --- |
| User | 사용자 | id, createdAt |
| Resource | 등록 리소스 | id, name, type, unit, cost, usage, need, meta |
| Budget | 사용자별 예산 상태 | resources[], limit, notes, purpose |
| AiRecommendation | AI 제안 | title, target, savings, grounds[], action, kind |

신규 사용자는 **빈 Budget**(리소스 0건)으로 시작한다. 초기 템플릿 리소스는 없다.

## 6. API 구성

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| GET | `/api/health` | 상태 확인 |
| POST | `/api/auth/signup` | 회원가입 |
| POST | `/api/auth/signin` | 로그인 |
| POST | `/api/auth/refresh` | Access Token 재발급 |
| POST | `/api/auth/signout` | 로그아웃 |
| GET | `/api/auth/me` | 현재 사용자 |
| GET / PUT | `/api/budget` | 예산·리소스 조회/저장 |
| POST | `/api/ai/recommend` | 절감 추천 생성 |
| POST | `/api/ai/report` | 보고서 생성 (SSE) |

상세 스키마는 [백엔드 API 명세서](../기능명세서/백엔드-API-명세서.md) 참고.

## 7. 리소스 카탈로그

- 리소스 유형 **20종** (EC2, RDS, S3, Lambda, DynamoDB, ALB …)
- 과금 단위 **8종** (시간, GB·월, 백만 건 …)
- 요금 옵션 **47개**, 무료 티어 및 사용 시간 프리셋 포함

상세 요금표는 [리소스 카탈로그](../리소스/리소스.md) 참고.
